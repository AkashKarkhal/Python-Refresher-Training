# 🎬 Movie Analytics Project

## 📌 Overview
A data analytics project built using MySQL, Python, Pandas, and Power BI to analyze movie data and create an interactive dashboard. The project demonstrates the complete workflow from data storage to visualization.

## 🛠️ Technologies Used
- MySQL Workbench
- Python
- Pandas
- SQLAlchemy & PyMySQL
- Matplotlib & Seaborn
- Microsoft Power BI

## 🚀 Project Implementation
- Imported movie dataset from CSV into MySQL.
- Connected Python with MySQL database.
- Retrieved and analyzed data using Pandas.
- Performed data cleaning and preprocessing.
- Generated insights from movie ratings, genres, directors, countries, and release trends.
- Created an interactive Power BI dashboard.

## 📊 Dashboard Highlights
- Total Movies KPI
- Average Rating KPI
- Maximum & Minimum Rating KPI
- Movies vs Series Distribution
- Top Genres Analysis
- Top Directors Analysis
- Country Distribution
- Rating Distribution
- Interactive Filters & Slicers

## 📈 Key Analysis
- Genre-wise Analysis
- Director-wise Analysis
- Country-wise Analysis
- Language-wise Analysis
- Rating & Metascore Analysis
- Top Rated Movies
- Year-wise Release Trends
